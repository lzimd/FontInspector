# Apple TrueType Reference Manual, Chapter 6

This directory is a generated mirror of Chapter 6 of Apple's TrueType Reference Manual. The mirror covers the Chapter 6 pages matching `Chap6*.html`. The mirror excludes other chapters and site chrome.

Upstream landing page: [https://developer.apple.com/fonts/TrueType-Reference-Manual/RM06/Chap6.html](https://developer.apple.com/fonts/TrueType-Reference-Manual/RM06/Chap6.html).

## Regeneration

Run the following commands from the repository root:

```sh
uv run -m specmirror truetype fetch
uv run -m specmirror truetype build
```

The build replaces generated files in this directory. Don't edit them by hand. Corrections belong in the versioned correction data under `scripts/specmirror/corrections/data/truetype/`.
